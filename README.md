# Aaron Petrini — portfolio

Plain HTML + CSS. No build step, no JavaScript.

- Edit text in `index.html`. Search for `YOUR-` and `[One-line description` to find the placeholders.
- Replace the images in `images/` with real screenshots (keep the file names, or update the `src` in `index.html`).
- Deploy: put the folder in a repo named `<username>.github.io`, push to `main`, and enable GitHub Pages in the repo settings.
