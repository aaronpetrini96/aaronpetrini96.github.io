VocalCompressor

Two classic compressor styles in one vocal plugin.

A personal C++/JUCE project covering both DSP and interface. It combines a fast FET-style unit (FET-76) and a smooth optical-style unit (OPT-2A), so you can run a vocal chain in one plugin with swappable order and independent bypass.

Main Features

FET-76

  • Input, Output, Attack and Release knobs. Attack and Release range from 1 to 7.
  • Ratio buttons from 4 to 20, plus an ALL mode that gets faster and stronger as the signal is pushed harder.
  • Asymmetric soft-clipper with a DC blocker, adding harmonic saturation that grows with ratio without changing loudness.
  • Mix knob for parallel compression.

OPT-2A

  • Gain and Peak Reduction knobs, and a COMP/LIMIT switch.
  • No attack or release controls. The release follows the signal, recovering faster on quiet passages and slower on loud ones.
  • The same soft-clipper class as the FET-76, set lighter, with a DC blocker.
  • Mix knob for parallel compression.

Extras

  • Signal Flow: swaps the order of the two stages with a click-free crossfade.
  • Gain reduction LED meters on each stage.
  • Oversampling across the whole chain, with latency reported to the host.
  • Preset manager with factory and user presets, and Undo/Redo.
  • Resizable interface with several sizes and a saveable default.
  • Global Bypass.
