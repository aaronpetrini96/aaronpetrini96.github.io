GuitarTools

GuitarTools makes mixing guitars fast and simple!

A personal project built in C++ with JUCE, covering both the DSP and the interface. It brings the processing I use most when mixing electric guitars into one plugin, designed to be quick and easy to use.

Main view

Plugin Demo Download (VST3 & AU) Source Code (GitHub)

Main Features

Tone Range

  • Low Cut / High Cut: high-pass and low-pass filters with cutoff ranges carefully limited for guitar mixing.
  • Slope: four selectable slopes for each filter: 12, 24, 36 and 48 dB/oct.

Clean-Up

  • Kill Reso: narrow cut with adjustable frequency to remove harsh resonances.
  • Clear Mud: wide dip that reduces low-mid buildup, with adjustable amount.
  • Tame Lows: band compressor that keeps the low end of chugs and palm mutes under control, with adjustable amount.
  • Each tool includes a MAX switch for more aggressive processing.

Color

  • Depth: low shelf filter with four selectable frequency modes and gain control.
  • Presence: high shelf filter with four selectable frequency modes and gain control.

Extra Features

  • Levels: input and output gain with peak meters and clip indicators.
  • Match Loudness: automatically keeps the output level equal to the input.
  • Low Tuning: shifts the low-end processing down for guitars in lower tunings.
  • Preset Manager: browser with factory and user presets.
  • Undo/Redo: steps back and forward through changes.
  • Resizable Interface: several window sizes, with a default you can save.
  • Tooltips: optional strip that describes each control on hover.
  • Global Bypass: switches all processing off for quick comparisons.
