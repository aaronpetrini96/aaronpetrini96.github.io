ExtremeComp

An aggressive vocal compressor for heavy vocals.

A compressor plugin for metal vocals. Besides compression, it applies EQ and saturation to give a powerful, nearly mix-ready sound.

Main view

Watch the demo Source code

Main Features

Compression

  • A single Compression knob controls the amount. Higher settings give a more aggressive, high-ratio effect, and lower settings give a gentler, more natural one.
  • Mix knob blends wet and dry signal. At 100%, only the wet signal is heard.
  • Auto Input Gain button sets the input level for the compression stage. You can also set input gain manually with a slider.

Tone

  • Saturation with two selectable modes, or off.
  • EQ applied based on the Compression value, with Body and Air knobs for fine-tuning.
  • The EQ can be placed before or after compression, and a preset high-pass filter can be enabled.

Extras

  • Preset saving/loading and global bypass.
  • Input/output gain sliders.
  • Gain reduction meter and clipping indicators.
